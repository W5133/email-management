# W5133 Email Management

R scripts for maintaining the W5133 mailing list in Google Sheets and preparing or sending individual Outlook emails.

See the [workflow and setup instructions](email_management/README.md).

Open `email-management.Rproj` in RStudio. The mailer is
`email_management/W5133_email.R`; review its send and preview settings before running it.

This repository was migrated from the `main` branch of
[W5133/w5133.github.io](https://github.com/W5133/w5133.github.io), including the current working-tree updates.
Earlier history remains in that repository.
